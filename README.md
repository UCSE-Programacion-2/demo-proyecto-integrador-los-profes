# Demo Proyecto Integrador — TurniMed Municipal (Programación II)

Repositorio **plantilla** para taller docente y demostración en aula: mismo esqueleto MERN que el proyecto integrador de la matería, con documentación y sprints orientados al caso **TurniMed Municipal** (gestión de turnos en salud pública). No reemplaza el enunciado oficial del año; sirve para practicar **GitHub, Projects, Issues, PRs, Classroom y metodología ágil** con un producto coherente.

## Uso como plantilla (GitHub Classroom)

1. Publicar este repo en la organización de la cátedra.
2. En **Settings → General**, activar **Template repository**.
3. Crear la asignación en [GitHub Classroom](https://classroom.github.com) eligiendo este repo como *starter code*.

Pasos detallados: [docs/taller/github-classroom-y-template.md](docs/taller/github-classroom-y-template.md).

## Reglas de contribución (alineadas al integrador)

- Flujo basado en ramas y **Pull Requests** hacia `main`.
- PRs con revisión (la cátedra define si son 1 o 2 aprobaciones).
- Trabajo trazable con **Issues** o tarjetas en GitHub Projects.
- Commits según [docs/convencional-commits.md](docs/convencional-commits.md); instalación de hooks: `node scripts/install-git-hooks.mjs`.
