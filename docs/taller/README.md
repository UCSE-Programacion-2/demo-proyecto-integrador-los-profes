# Taller docente — Demo Proyecto Integrador (TurniMed)

Este paquete documenta cómo dictar el **taller especial** con tres docentes usando este repositorio como **plantilla** para GitHub Classroom y como **caso de estudio** alineado al [Product Brief](../product-brief.md).

## Orden sugerido de la sesión (visión general)

1. Presentar el brief y las épicas (PO).
2. Mostrar el repo plantilla y el material del curso (todos).
3. Crear o mostrar **Issues** tipo épica e historia de usuario enlazadas al brief (PO + SM).
4. Configurar **GitHub Projects**, labels y **milestones** (SM).
5. Recorrer **Sprint 0** y **Sprint 1** en el tablero: mover tarjetas, asignar, cerrar con PR (Developer + SM).
6. Cierre: enlace a GitHub Classroom y tarea para que los alumnos repliquen (todos).
